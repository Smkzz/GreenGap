# First-run usability sessions

Five fresh-context evaluators must use the frozen packaged candidate, not an
editable source tree. Each session records consent, OS/Python, install method,
the first command chosen, whether the result was understood, whether the CI
workflow was integrated without maintainer intervention, and whether the
collection execution boundary was understood.

The required threshold is at least four of five completing install ->
understand result -> integrate, and all five understanding that trusted
collection executes repository code. Agent simulations must be labelled
separately from consenting human sessions. No human sessions have been run or
claimed by this worktree; this is an external launch blocker.
